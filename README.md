# contact-card

Digital Business Card for Akshay Srivastava — a lightweight, accessible single-page card with:

- Monogram, name, title and brief bio
- Interactive skill chips with descriptions and LinkedIn link
- Share button (Web Share API / clipboard fallback)
- Download PNG (via html2canvas)

Live demo (GitHub Pages): https://akshay01123.github.io/contact-card/

Run locally:

```bash
cd /Users/akshay/Desktop/Projects/contact-card
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```

Files of interest:

- `index.html` — main markup
- `style.css` — styles and layout
- `script.js` — interactivity (tooltips, share, download)
